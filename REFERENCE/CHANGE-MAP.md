## 需要审阅的语义变化与风险

1. **审查门槛**：取消申请奇偶与“所有重大必三轮”。风险是把复杂决定误判普通；控制为首次路线仍重大、重大必有真实独立反方、未解决的重大异议须升级，用户始终保留决定权。
2. **文件权威**：单文件改为按职责三文件。风险是版本不同步；控制为实例指针和版本联结、单一状态整合者、依赖一致性检查和同步失败标记。
3. **时间与恢复**：不让估计强迫停工，明确暂停与结单。风险是把新任务伪装原轮无限续接；控制为原指令/目标边界、原 W-ID、已用账不返还、资源异常与真正停止条件、新独立任务仍扣轮。
4. **记录成本**：用户指南不再兼任实时状态副本，普通事项不用完整模板。风险是交接遗漏；CORE 规定 STATE 的最小技术信息和每轮中文用户交接，重大因果记录仍冻结。
5. **停滞预警**：新增两轮诊断，保留原效果复盘节奏。风险是只认“测试通过”；明确有效失败证据也是进展，预警不自动失败或改路线。
