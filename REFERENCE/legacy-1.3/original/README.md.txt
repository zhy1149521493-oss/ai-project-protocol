# 通用 AI 项目执行制度

**中文（默认）** | [English](README.en.md)

一套面向复杂 AI 协作项目、可跨项目复用的执行制度与 Codex Skill。它帮助用户和 AI 明确交付目标、控制技术路线和工程对话预算、复用证据、记录重要决策，并保持可靠交接。

制度可跨项目复用，Skill 入口面向 Codex；其他执行环境可手动读取完整工程版，但其自动加载能力需分别验证。

当前制度版本：**1.3**。每一步以第一轮完成完整任务为目标；后续轮次用于真实问题的测试、修复和验收。内部子 Agent、并行任务和工具调用不额外扣轮；明确任务范围内的一次授权覆盖必要的执行过程，无需逐个动作重复请示。具体边界和审批要求以工程版为准。

## 试用方式

克隆或下载**完整仓库**，保持目录结构。让执行 Agent 读取 `SKILL.md` 以及其引用的完整工程主文档。例如：

> 请读取本仓库的 SKILL.md 和它引用的完整工程制度，解释主要规则。此次仅阅读，不开始应用项目，不修改项目状态。

如需自动发现 Skill，请先检查当前环境实际支持的搜索路径，再安装完整文件夹；不要只复制 `SKILL.md` 而遗漏依赖。本仓库提供指令和文档，不是自动强制执行规则的服务。

## 语言

首页和文档索引默认中文，提供对应英文页面；工程版、用户版和模板保持中文，历史审查与决策记录保留原语言。英文导览不是整套制度的完整英译，也不构成另一份权威规则。

本包尚未绑定任何应用项目。读取或安装它不会自动授权或启动任何应用工程。
