# 按需记录格式

适用候选 2.0.0-rc1；规范只以 [CORE](../CORE.md) 为准。以下是空格式，不是已发生的批准。字段已有就引用，不复制原日志。真实项目记录保存在该实例，不写进共享模板。复制后按实际位置调整相对链接。

## 普通工单短记录

普通实现、Bug、测试和回归直接记入 STATE 的 W 索引或已有工单：

```text
W-ID / S-ID / P-ID；原独立主指令与日期/来源：
状态：未开始 / 执行中 / 技术暂停（未结束） / 已结束；开始、结单或恢复证据：
整步完整目标 / 本轮验收与授权引用：
动作与观察、已排除什么、共同根因或仍未知：
产物路径与版本 / 原始方法和结果 E-ID / 适用限制：
C/A/U/Q/R及唯一扣账事件；内部工作量与实际资源另列：
批准硬上限 / 实际平台限制 / 内部估计（不当硬停）：
余项、越界及真实依赖、可继续项、清理/恢复核验：
技术暂停检查点或已结束结果 / 下一准确动作：
同P诊断记录及连续无效次数：新证据/排除假设/不同可验证方案；连续两次均无则停止重复并交用户判断：
```

## 主步骤与路线压缩

采用后填入 ROUTE，保存全部主步骤，实时预算引用 STATE：

```text
S-ID / 唯一主要交付与最终验收关联：
问题与时机：解决什么问题 / 为什么现在做 / 与项目最终目标的关系：
输入版本、可复用成果及E-ID：
首轮完整交付目标 / 已知规模、依赖、权限阻断及证据：
必需验收：观察条件、方法、环境、失败判据、原始证据位置：
进入下一步依赖 / 关键风险、重大阈值和独立复核检查点：
操作/资产/风险/清理恢复授权、硬资源限制及停止条件引用：
后续轮次只留实际测试修复/验收或真实阻断余量，不预排主要开发：
```

压缩映射：`初稿步→≤7步→目标5步；理由；成果复用；输入/并行条件；保留验收及依赖；新增风险`。6–7步的不可合并理由、8–10步的例外批准另列；不得仅合并标题。

## 正式记录的共同最小正文

只有触发 CORE 正式记录条件时创建 D-ID；预算使用 B-ID 并关联相应决定。可以在一个记录合并适用模块。

```text
D-ID / 类型 / 日期 / 作者 / 制度、路线、状态版本：
关联 S/W/P/B 与旧决定；重大归类和审查深度的依据：
当时目标、背景、主要结果和真实验收缺口；事实/E-ID、推断、未知：
原路线/理由、保留或放弃的重要成果；继续/替代/最小验证的未来成本风险：
用户原话及来源（未提供写未提供）：
AI整理、技术新增分析、反方异议/回应（与原话分开）：
推荐、会改变推荐的证据、待接受风险、成功/失败与停止条件：
实际决定及当时理由；批准对象、额度/权限/路线、来源、日期、生效条件：
决定状态 / 证据状态 / 生命周期；冻结时结果未知就写未知：
后续验证责任、方法、触发点、真实结果/影响的追加位置：
```

### 预算耗尽与追加模块

- B-ID/P-ID 与累计申请序号；正式提交/实质替代来源，拒绝或撤回也保留；多问题分配但总额≤3。
- 引用 STATE 的逐轮成果、C/A/U/Q/R、已花资源、未过验收/真实阻断及旧尝试为何不足。
- 回看最终目标与偏航、预期新结果、未来成本和性价比；比较继续、替代、最小区分验证，不按沉没投入推导继续。
- 请求1–3轮的具体用途、停止条件、失败后的判断入口；不预批下一次。
- 是否重大及依据、反方/多轮是否触发；普通追加不因序号升级，也不豁免重大审查。
- 用户明确批准/部分批准/拒绝/暂缓、来源、实际额度与条件；未批不更新 A，路线与预算分别生效。

### 重大决定与路线变更模块

- 实际提案方/独立反方/用户、独立性限制，关键反例及回应；缺失如实标记。
- 用户从提案阶段的实际反馈；理解复述、AI解释、用户二审及精确批准来源，不能代填。
- 多轮触发及依据；需要时真实完成提案反例、回应检验、交换立场三阶段，不制造对话；未解决分歧和最小取证另列。
- 旧→新路线、验收、成果与预算继承；哪些假设失效、哪些仍有效，不把后来事实倒写。
- 路线/预算/受控资产等分别批准；条件核证及完整 ROUTE 更新、STATE 版本同步。

### 失败与停滞模块

引用已有 W/E：预期与观察、已排除假设、共同根因、无效重复及禁止重试条件；保留成果与下一最小区分验证。记录两轮诊断/五轮复盘/制度效果检查哪些被触发，合并处理而不写三份同义报告。正常修复沿用原授权，真正越界只停相关项。

### 规则或版本迁移模块

旧规则/版本→候选；实际问题与证据局限；保留/修改/合并/参考化/删除对应；收益、维护成本和风险；用户采用或拒绝的对象/来源/生效点；预算/路线/授权/历史继承与恢复方案。只制作候选时，状态写“提议中，未批准采用”。
