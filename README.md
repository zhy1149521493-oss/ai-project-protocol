## 结构与使用

规则只在 CORE，批准的目标/完整路线/验收只在 ROUTE，实时状态/工单/预算只在 STATE；历史、模板和详细取舍按需看 REFERENCE。普通轮次更新 STATE 和真实证据，中文用户报告从同一事实生成，不复制第二本状态账。详见 [文档索引](docs/README.md)。

这是面向 Codex 的 Skill；其他 Agent 可按路径读取文件，不能因此推定自动加载。当前只在隔离目录按文件审阅，不安装同名入口，不覆盖已采用版本。审阅提示：

```text
请读取候选目录的 SKILL.md，并完整读取 CORE.md、ROUTE.md、STATE.md。
本次只做候选审阅或纸面检查，不替换已安装Skill，不迁移任何项目，
不创建应用路线、不改变授权或工程预算。按需核对 CHANGE-MAP 和旧版存档。
```

真实项目采用必须另行批准并核对迁移前后预算、路线、授权、历史和未解问题。[旧版归档](REFERENCE/legacy-1.3.zip)及[校验清单](docs/BASELINE.json)保留原始版本；归档不是当前执行规则。

本候选未加入自动检查框架、真实项目样例或开源许可证。许可证和是否正式采用由用户决定。读取量下降是文档测量结果，不是对真实工程效率或 Agent 遵从的证明。
