This package supports review of the 1.3→2.0.0-rc1 candidate, not active project execution. It needs readable Markdown, with no application build, AI API or new runtime dependency.

- Read [CORE](../CORE.md), the complete [ROUTE](../ROUTE.md) and latest [STATE](../STATE.md) in full each round after adoption.
- Review [rule mapping](../REFERENCE/CHANGE-MAP.md), [record formats](../REFERENCE/RECORDS.md), [migration](../REFERENCE/MIGRATION.md) and the [proposed decision](../REFERENCE/D-0004-candidate-refactor.md) when relevant.
- Actual checks, reading-volume measurements and limits are consolidated in [VALIDATION](VALIDATION.md); original-file hashes are in [BASELINE](BASELINE.json).

Use file-based review without installation or publication. Explicit adoption approval and migration reconciliation are required before changing a real instance. No budget, route, authorization or unresolved history is reset. The English pages are navigation; Chinese CORE defines the candidate rules.
